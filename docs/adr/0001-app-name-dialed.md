# ADR 0001 — App name: Dialed

**Status:** Accepted  
**Date:** 2026-06-10

## Context

The app was called "Bike Geo Compare" (page title) and "BikeGeo" (nav). Neither name stuck — "Bike Geo Compare" is descriptive but forgettable, "BikeGeo" is generic.

## Decision

Rename the app to **Dialed**.

## Alternatives considered

| Name | Why rejected |
|---|---|
| Bike Geo Compare | Descriptive but not memorable |
| BikeGeo | Generic, no personality |
| Fitmaat | Dutch pun (fit + maat = size/buddy), but app is in English |
| Koersmaat | Cycling-specific Dutch (koers + maat), same language mismatch |
| Rosmaat | "Ros" (steed) + maat — poetic but too archaic |
| Frame of Reference | Clever (bike frame + coordinate system), but long |
| Geodrome | Geo + velodrome — fun but obscure |
| Truefit | Wheel truing + true fit — less punchy |

## Rationale

"Dialed" is cycling slang for a perfectly set-up bike (*"fully dialed in"*). The name:
- Means exactly what the app helps you achieve — a dialed position
- Is immediately understood by cyclists without explanation
- Works as a single word (no suffix needed)
- Feels like a tool a cyclist would trust
